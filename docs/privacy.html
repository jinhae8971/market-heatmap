개인정보처리방침

마켓 히트맵 (com.jinhae.heatmap) · 최종 수정 2026년 8월 8일

요약: 이 앱은 어떠한 개인정보도 수집하지 않습니다. 계정, 로그인, 회원가입이 없으며 기기에 저장하는 개인 식별 정보도 없습니다.

1. 수집하지 않는 정보

이 앱은 이름, 이메일, 전화번호, 위치, 연락처, 사진, 기기 식별자를 포함한 어떠한 개인정보도 수집·저장·전송하지 않습니다. 광고 식별자를 사용하지 않으며 분석 도구나 광고 SDK를 포함하지 않습니다.

2. 앱의 동작 방식

이 앱은 공개된 웹페이지(GitHub Pages)에 게시된 시장 데이터를 불러와 표시합니다. 이 과정에서 발생하는 통신은 표준 웹 요청이며, 사용자를 식별하는 정보는 포함되지 않습니다.

  • 표시되는 데이터: 상장 종목·암호화폐의 공개 시세, 시가총액, 등락률
  • 기기에 저장되는 것: 화면 표시 속도를 위한 웹 캐시(언제든 앱 데이터 삭제로 제거 가능)

3. 제3자 서비스

데이터를 표시하기 위해 다음 서비스에 접속합니다. 각 서비스는 자체 개인정보처리방침에 따라 IP 주소 등 일반적인 서버 접속 기록을 남길 수 있습니다.

  • GitHub Pages — 앱 화면과 데이터 파일 제공
  • Yahoo Finance, CoinGecko — 시세 원천 (데이터 수집 서버에서만 접근하며, 앱이 직접 호출하지 않습니다)

4. 아동

이 앱은 아동을 대상으로 하지 않으며, 연령과 무관하게 개인정보를 수집하지 않습니다.

5. 투자 판단에 관한 고지

표시되는 정보는 공개 데이터를 시각화한 참고 자료이며 투자 권유나 자문이 아닙니다. 데이터는 하루 두 번 갱신되는 지연 정보이고 오류나 누락이 있을 수 있습니다. 투자 결정과 그 결과에 대한 책임은 이용자 본인에게 있습니다.
