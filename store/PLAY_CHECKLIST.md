계정 인증이 끝나면 아래 순서대로만 하면 된다. 값은 그대로 복사해 넣을 수 있게 적었다.

## 준비된 파일

| 파일 | 용도 |
|---|---|

## 1. 앱 만들기

- 앱 이름: **마켓 히트맵**
- 기본 언어: 한국어
- 앱/게임: **앱** · 무료/유료: **무료**

## 2. 앱 설정 (좌측 '앱 설정' 항목을 위에서부터 소진)

**개인정보처리방침**
```
https://jinhae8971.github.io/market-heatmap/privacy.html
```

**앱 액세스 권한** — 로그인이 없으므로 *모든 기능을 제한 없이 사용 가능* 선택

**광고** — 아니요 (광고 없음)

**콘텐츠 등급** — 설문에서 카테고리는 *유틸리티·생산성·기타*, 폭력·성적 내용·도박 등 전 항목 '아니요'

**타겟층** — 18세 이상. 아동에게 어필하지 않음

**데이터 보안** — 핵심 답변
- 데이터를 수집하거나 공유합니까? → **아니요**
- 전송 중 암호화 → 예 (HTTPS만 사용)
- 데이터 삭제 요청 경로 → 해당 없음 (수집하는 데이터가 없음)

**정부 앱 / 금융 기능** — 아니요.
※ 이 앱은 주식·암호화폐 **정보 표시**만 하고 거래·중개·투자자문 기능이 없다.
설문에서 거래나 자문 기능이 있다고 답하면 금융 서비스 심사 대상이 되어 서류를
요구받는다. 실제로 없으므로 '아니요'가 맞다.

## 3. 스토어 등록정보

**간단한 설명** (80자 이내)
```
전세계 주식·암호화폐를 트리맵 한 장으로. 면적은 시가총액, 색은 등락률.
```

**자세한 설명**
```
한국·일본·유럽·미국 주요 종목과 암호화폐를 하나의 히트맵으로 봅니다.

· 타일 면적은 달러 환산 시가총액, 색은 등락률
· 시장별 탭 전환, 섹터 묶기, 종목을 누르면 현재가·시총 상세
· 평일 하루 두 번(한국·일본 마감 후, 미국·유럽 마감 후) 자동 갱신

계정도 로그인도 필요 없습니다. 개인정보를 일절 수집하지 않습니다.

표시되는 정보는 공개 데이터를 시각화한 참고 자료이며 투자 권유가 아닙니다.
```

**스크린샷** — 휴대전화 최소 2장 필요. 앱을 켜고 캡처하면 된다.
권장: ① 전체 탭 히트맵 ② 종목 상세 시트가 열린 화면

## 4. 내부 테스트 트랙

1. 테스트 → 내부 테스트 → 새 버전 만들기
2. `market-heatmap-1.0.aab` 업로드
3. **Play 앱 서명 사용에 동의** — 배포용 키를 Google이 관리하므로,
   업로드 키를 잃어도 앱이 죽지 않는다
4. 출시 노트:
   ```
   <ko-KR>
   첫 버전. 한국·일본·유럽·미국·암호화폐 176종목 히트맵.
   </ko-KR>
   ```
5. 테스터 목록 만들기 → Gmail 주소 등록 (최대 100명)
6. 검토 후 출시 → 생성된 참여 링크를 테스터에게 전달

테스터는 링크로 참여에 동의한 뒤 Play 스토어에서 설치한다.

## 다음 버전을 낼 때

```bash
ANDROID_HOME=<SDK경로> BUNDLETOOL=<bundletool.jar> bash android/build-aab.sh
```

`AndroidManifest.xml`의 `versionCode`를 반드시 올려야 한다 — 같은 번호는
업로드가 거부된다. 앱 화면(히트맵)만 고치는 경우에는 재빌드가 필요 없다.
Pages에 푸시하면 다음 실행에 반영된다.
